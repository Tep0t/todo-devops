# Todo DevOps Application

This is my ToDo app for the DevOps Application Development assignment. It is built with Next.js and lets me add, complete, and delete tasks, with dark and light themes.

## Tools

- Next.js for the app
- Git and GitHub for version control and sharing the project
- Git Flow branches for feature work, development, releases, and production
- Vercel for Development (`develop`), Staging (`release/v1.0`), and Production (`main`)

## Run locally

Install the dependencies with `npm install`, then start the development server with `npm run dev`.
